# helpdesk-api

Серверна частина служби технічної підтримки коледжу на NestJS 12.
Навчальний проєкт освітнього компонента «Розробка клієнт-серверних застосувань» (розділ 3).

```
npm install
npm run start:dev      # http://localhost:3000/api/v1/health
npm run check          # oxlint + tsc + модульні та e2e-тести (Vitest)
```

Потрібен Node.js 24 LTS. Проєкт створено командою `nest new` (ES Modules, Vitest, oxlint, TypeScript 6).
Вимоги поточної практичної роботи – у файлі SPEC.md.
